## Hammerspoon

Hammerspoon requires Accessibility permissions to work correctly:

1. Open System Settings > Privacy & Security > Accessibility.
2. Find Hammerspoon in the list.
3. Turn the toggle off, and then back on again.
4. Fully restart Hammerspoon.

## `chsh`

To change to `zsh` use 

```sh
chsh -s /path/to/shell
```

Remember to log out completely and log back in for changes to take effect.
